# Photos Tri

Appli iOS personnelle pour faire du vide dans la photothèque : tri par taille, par lieu, doublons exacts et photos similaires. Tout est calculé sur l'iPhone, rien n'est envoyé en ligne. La suppression passe par la confirmation iOS et les éléments vont dans « Supprimés récemment ».

## Obtenir l'appli
1. Onglet **Actions** du dépôt > **Build IPA** > **Run workflow** (ou un simple push).
2. Quand c'est vert, ouvre l'exécution et télécharge l'artefact **PhotosTri-ipa** (zip contenant `PhotosTri.ipa`).
3. Installe `PhotosTri.ipa` sur l'iPhone avec Sideloadly ou AltStore (Apple ID gratuit, validité 7 jours).
